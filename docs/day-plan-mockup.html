行程篮 · 自动算百公里

把想走的路线加进来，按天排好，系统按每天的首尾位置推荐住宿，最后导出一份行程单。

这是交互样例（纯静态页面，数据写死在 JS 里），用来确认 4 件事：
⚠️ 定稿时改了两点：① 地图不做 Tab，保持常驻在原来的位置（这里没画地图，就是那个位置）； ② 不做旧版本兼容，旧行程篮里的路线全部落在「待安排」，自己拖一次就行。
  1. 能不能拖：路线卡可以直接拖到「Day N」列 / 拖回「待安排」；也可以用卡上的下拉和 ↑↓ 按钮（手机上主用这个）。
  2. 每天自动算什么：里程 / 约耗时 / 爬升 / 难度，>20km 或 >6.5h 会橙色警示。
  3. 住宿怎么推：粉色卡是「推荐住宿区 + 理由」，底下带 ₩ 的是候选清单——注意候选清单目前没有真实数据，是拿来确认版式的示例（示例数据）。
  4. 行程单长什么样：点右上角「导出行程单」，里面也有「打印/存 PDF」和「复制 Markdown」。
试试把 10-1 加波岛 拖进某一天 —— 会触发「需坐船、建议住岛上」的规则。
